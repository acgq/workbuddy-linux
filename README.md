# WorkBuddy for Linux

腾讯官方 Linux 版本更新较慢，本项目将 macOS 版 WorkBuddy 移植到 Linux，为 Linux 用户提供较新的客户端功能和体验。

这是非官方移植项目，构建产物由 GitHub Actions 生成，可在 [Releases](https://github.com/acgq/workbuddy-linux/releases) 下载。

[官方 Linux 版本检查更新接口](https://copilot.tencent.com/v2/update?platform=workbuddy-linux-x64-deb)

本仓库的打包脚本采用 MIT License；WorkBuddy 应用及资源的权利归腾讯或相应权利人所有。
